这三份原文从现有 `F5_leave_and_scope` 原样复制，作为独立维护的业务资料起点。本次没有扩写条款；它仍是小型知识库，尤其请假制度目前只有申请审批规则。凭证要求、育儿假天数、具体员工的审批进度均不在资料中，不能推断补全。
