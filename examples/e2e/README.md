# 完整端到端验收材料

这里对应题目要求的最终完整 Agent 业务验收，当前尚未执行，只有目录说明。已有独立检索与占位工具接入冒烟分别在 [retrieval](../retrieval/README.md) 和 [总索引](../README.md)，不计作完整验收。

后续从正式入口提交问题与可选历史，经过实际模型决策、工具调用、观察、后续决策或结束，检查回答、引用、资料缺口和任务状态。至少覆盖明确答案、文档冲突、资料外问题、改写、上下文追问及工具失败，并保留至少两条随不同工具结果调整动作的真实模型路径。

实际执行后按相同 case_id／run_id 配对保存：

- `inputs/<case_id>/<run_id>/`：当次问题、历史、公开配置、资料快照与必要的故障注入说明。
- `outputs/<case_id>/<run_id>/`：实际结果与执行摘要。
- `traces/<case_id>/<run_id>/`：全过程、模型请求、工具参数与返回、证据，以及文件校验清单。
- `reports/`：自动断言与评估侧核对结果；逐次指标使用相同 case_id／run_id。

变体和模式写入输入与运行元数据，run_id 唯一关联当次运行；上下文场景需关联前后轮 ID。真实模型与离线 Mock 明确区分，Mock 仅验证流程。没有发生的请求或工具执行不得补造记录；失败与修复后的记录都应保留。预期判据不传给运行模型，只有实际执行并核对后才标为通过。
